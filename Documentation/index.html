Assets and Images

Main template assets are stored in html/assets. This folder contains logos, favicon, and all gallery or hero images used across the template.

If you replace images, keep the same file names or update the related HTML references. For alternate visuals, check the html/assets/version-2 folder as well.

Header and Logo
<a class="navbar-brand header-logo" href="#home">
  <img src="assets/logo-black.png" alt="Hotel Logo" height="40" class="logo-dark">
  <img src="assets/logo-white.png" alt="Hotel Logo" height="40" class="logo-light">
</a>

Replace html/assets/logo-black.png and html/assets/logo-white.png with your own logo files if needed.

Favicon
<link rel="icon" type="image/png" href="assets/ico.png">

The favicon file is located at html/assets/ico.png.

CSS and JavaScript

Main CSS Files
  • Main style: html/css/style.css
  • Dark theme adjustments: html/css/dark.css
  • Extra custom styles: html/css/ext-style.css
  • Framework and libraries: bootstrap.min.css, swiper-bundle.min.css, all.min.css

For most visual changes such as colors, spacing, typography, sections, cards, and layout, start from html/css/style.css.

Main JavaScript Files
  • Main interactions: html/js/main.js
  • Hero or slider behavior: html/js/slider-custom.js
  • Smooth scrolling: html/js/lenis.min.js
  • Vendor scripts: jquery-3.7.1.min.js, bootstrap.bundle.min.js, swiper-bundle.min.js
Example CSS Include
<link href="css/bootstrap.min.css" rel="stylesheet">
<link rel="stylesheet" href="css/swiper-bundle.min.css">
<link rel="stylesheet" href="css/all.min.css">
<link rel="stylesheet" href="css/style.css">

Email and Forms

Contact Form Setup

The contact form backend file is html/contact-submit.php. Update the email recipient inside that file before using the form on a live server. 

// Example
$to = 'your-email@example.com';

Make sure your hosting supports PHP mail delivery.

Customization Tips

Text and Content

Edit text content directly inside the corresponding HTML page. Homepage sections such as hero, about, facilities, rooms, gallery, and CTA are defined in each demo file.

Images

Replace image files in html/assets and keep the same dimensions when possible to preserve the layout quality.

Colors and Typography

Global visual settings are mainly controlled from html/css/style.css. Search for root variables, section titles, buttons, cards, navigation, and footer rules to update the design.
